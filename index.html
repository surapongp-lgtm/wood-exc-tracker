Admin สามารถสร้างบัญชีผู้ใช้งานใหม่ กำหนดสิทธิ์ (Admin/Staff), สาขาสังกัด และเปลี่ยนรหัสผ่านให้กับพนักงานได้

Username ชื่อ-นามสกุล สิทธิ์การใช้งาน (Role) สาขาสังกัด รหัสผ่าน (Password) จัดการ
ตั้งค่าการเชื่อมต่อ Google Sheets Backend API (เฉพาะ Admin)

โปรแกรมจะเชื่อมต่อกับ Google Sheets ของคุณผ่าน Google Apps Script Web App URL เพื่อให้พนักงานและ Admin ใช้งานบันทึกข้อมูลร่วมกันแบบ Real-time

วาง Web App URL ที่ได้จากการ Deploy Google Apps Script

วิธีตั้งค่า Google Sheets (3 ขั้นตอนง่ายๆ):

  1. สร้าง Google Sheet ใหม่ใน Google Drive ของคุณ
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script แล้วนำโค้ดจากไฟล์ google_apps_script.gs ไปวาง
  3. กด การทําการใช้งาน (Deploy) > การทําการใช้งานใหม่ (New deployment)
    • Select type: Web app
    • Execute as: Me (อีเมลของคุณ)
    • Who has access: Anyone (ทุกคน)
  4. คัดลอก Web App URL มาวางใส่ในช่องด้านบนนี้แล้วกดบันทึก
